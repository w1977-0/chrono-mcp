# Security Policy

## Supported Versions

Only the latest release on `main` is supported.

## Reporting a Vulnerability

This is a zero-dependency, single-file project: the attack surface is your
own Python interpreter and the MCP client that spawns it. If you believe you
found a security issue, open a private security advisory at
https://github.com/w1977-0/chrono-mcp/security/advisories — please do not
open a public issue for vulnerabilities.
